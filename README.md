# Handwriter — распознавание рукописного текста

Настольное приложение: фото страницы → текст. Слева фотография, справа
готовая расшифровка в редактируемом поле. Работает офлайн, всё считается
на вашем компьютере.

Окно — один фиксированный размер по макету из Figma (`design/main.svg`):
своя строка заголовка, стеклянные панели, кнопки Open photo / Save text /
Copy all и поворот фото на четверть оборота. Под фото — увеличение до 800%.

Читать умеет двумя способами:

- **построчно** — режет страницу на строки и читает каждую отдельно,
  красит их по уверенности модели. Работает на любой машине, даже без
  видеокарты.
- **страница целиком** — всю фотографию сразу смотрит модель Qwen3-VL: она
  сама держит порядок строк, не спотыкается о просвечивающий с обратной
  стороны текст и читает заметно точнее. Нужна видеокарта примерно на 8 ГБ.
  В первый раз докачивает ~6 ГБ.

Способ приложение выбирает само, по видеокарте: от 8 ГБ читает страницу
целиком, иначе построчно. Если посреди работы видеопамяти не хватит, оно
само перейдёт на построчное чтение и перечитает страницу.

Перед чтением фотография обрезается по краю листа, выравнивается по наклону
и, если это разворот тетради, делится на две страницы. Последнее важнее всего:
без деления строки ищутся сразу по двум колонкам, и на одной из проверочных
страниц ошибка падала с 54% до 12% только от того, что развороты стали
делиться правильно.

## Установка на Windows

Скачайте проект: зелёная кнопка **Code → Download ZIP**, распакуйте.
Затем в распакованной папке:

1. Двойной клик по **`install.bat`** — поставит всё необходимое.
   Занимает 10-20 минут, нужен интернет. Запускается один раз.
2. Двойной клик по **`start.bat`** — откроет приложение.

Всё. Ничего вводить в командной строке не нужно.

## Обновление

Двойной клик по **`update.bat`** — скачает свежую версию, заменит файлы
приложения и сам доустановит всё новое. Скачанные модели и ваши фотографии
при этом остаются на месте, заново качать их не нужно.

При самом первом запуске приложение докачивает модель распознавания
(1.3 ГБ), поэтому окно появится через несколько минут. Дальше — за секунды.

Нажмите **Open photo** и выберите изображение. Для пробы в папке лежит
`test_page.jpg`. Если фото легло боком, круглая кнопка рядом с Copy all
повернёт его на четверть оборота и прочитает заново.

Фото увеличивается кнопками «−» и «+» под ним или колесом мыши с зажатым
Ctrl; увеличенное можно двигать мышью, двойной щелчок возвращает к размеру
окна. Окно перетаскивается за строку заголовка.

### Если приложение написало, что работает на процессоре

Значит, версия PyTorch не подходит к вашей видеокарте — обычно так бывает
с очень новыми картами (RTX 50-й серии) или наоборот с очень старыми.
Приложение продолжит работать, но медленнее в несколько раз.

Двойной клик по **`fix_gpu.bat`** — он подберёт подходящую версию сам,
перебирая варианты. Может занять время: каждая попытка это закачка ~2.5 ГБ.
`install.bat` делает эту проверку сам, так что отдельно запускать
`fix_gpu.bat` нужно, только если сообщение появилось после обновления.

Пока приложение работает на процессоре, оно читает только построчно:
модели для чтения страницы целиком нужна именно видеокарта.

## Установка вручную (Linux, macOS или если хочется через терминал)

```bash
git clone https://github.com/ulyagordeenko-prog/handwritingOCR.git
cd handwritingOCR

curl -LsSf https://astral.sh/uv/install.sh | sh   # менеджер пакетов uv
uv sync                                           # библиотеки
uv run python setup_language_model.py             # языковая модель, 529 МБ
uv run python run_app.py                          # запуск
```

Языковая модель необязательна — без неё приложение работает, просто выбирает
вариант прочтения чуть хуже. Видеокарта NVIDIA тоже необязательна: без неё
считает на процессоре, медленнее.

## Как читать результат

Цвет фона под текстом означает уверенность модели:

- белый — уверена, скорее всего верно
- жёлтый — сомневается, стоит взглянуть
- красный — не уверена, почти наверняка нужна правка

Текст редактируется прямо в окне; «Сохранить текст» выгружает `.txt`
уже с вашими правками.

| `src/ocr_project/page_reader.py` | читает страницу целиком: Qwen3-VL, сжатая до 4 бит |
| `src/ocr_project/rescorer.py` | выбирает вариант, больше похожий на русский язык |

## Точность

Ошибка на символ (CER) на 60 строках, не участвовавших в обучении:

| | CER |
|---|---|
| TrOCR-ru без дообучения | 21.9% |
| построчно, с адаптером из этого репозитория | 6.9% |
| строки из набора данных, Qwen3-VL без дообучения | **4.0%** |

На целых фотографиях страниц, а не на готовых строках, цифры совсем другие —
15.9% ошибки на символ у Qwen3-VL по шести разворотам школьных тетрадей.
Разница не в модели, а в том, что фотографию страницы сначала надо разобрать:
на готовых строках эта работа уже сделана за нас.

Что проверялось и не подтвердилось, чтобы не проверять заново:

| Идея | Результат |
|---|---|
| Резать страницу на полосы ради разрешения | 16.1% против 15.9% — ничья, код убран |
| Читать построчно нашей же нарезкой | 40.5% — вдвое хуже и вдвое дольше, убрано |

## Ограничения

- В построчном режиме текст, просвечивающий с обратной стороны листа,
  распознаётся как отдельные строки. Помечается низкой уверенностью, но не
  отсеивается. В режиме «страница целиком» такого не происходит.
- В режиме «страница целиком» подсветки по уверенности нет: модель читает
  всё разом и не сообщает, где сомневалась.
- Слитный курсив на выцветших бланках (подписи в штампах) читается плохо.
- Одна страница обрабатывается около минуты на слабой видеокарте.
